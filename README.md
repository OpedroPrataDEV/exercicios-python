# Exercícios de Python

Resolução de exercícios em Python de várias fontes: BeeCrowd, faculdade e cursos.

## Fontes

- `beecrowd/`: problemas do BeeCrowd (antigo URI Online Judge). Este repositório tem só as minhas soluções; os enunciados pertencem à plataforma.
  - `iniciante/`: problemas da categoria Iniciante, de 1021 a 1060.
  - `outras-categorias/`: demais problemas, ainda por separar por categoria.
- `faculdade/prog-1/`: listas de exercícios da disciplina de Programação 1.
  - `funcoes/`: lista de funções (Ex01 a Ex09).
  - `vetores/`: lista de vetores (Ex01 a Ex07).

Novas fontes ganham uma pasta própria conforme eu avançar.

## Convenções

- Um arquivo por problema, nomeado `BeeCrowd_<número>.py`.
- Um commit por problema.
- As soluções leem a entrada pelo teclado (`input()`), como pede o BeeCrowd.

## Como executar

```bash
python BeeCrowd_1021.py
```
